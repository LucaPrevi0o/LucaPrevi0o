# Hi, I'm Luca Previati

I'm a Master's student in **Computer Engineering for Automation** at the [University of Ferrara](http://unife.it), with a Bachelor's degree in **Electronics and Computer Engineering** from the same university.

I like building software across the stack: from Ruby on Rails APIs and Angular frontends to lower-level C/C++ and Java, embedded-flavoured projects, data processing, and the occasional machine learning experiment.

- Bachelor's thesis: *Data extraction from a 4D MIMO radar*
- Supervisors: [Prof. Andrea Conti](https://ieeexplore.ieee.org/author/37266585500), [Dott. Ing. Alessandro Vaccari](https://ieeexplore.ieee.org/author/252534149252120)
- Final score: **99/110**

Outside coding life: average nerdy
  - Videogames and stuff: competitive Pokemon player, casual Nintendo party games enjoyer
  - Music and stuff: obsessed metalhead, Linkin Park and Breakin Benjamin addicted
  - Motorsport and stuff: Formula 1 and Ferrari incurable fan

## Featured Repositories

- [ShopBackend](https://github.com/LucaPrevi0o/ProgSistWeb-ShopBackend) and [ShopFrontend](https://github.com/LucaPrevi0o/ProgSistWeb-ShopFrontend)
  - Repositories for a full-stack e-commerce website developed for university exams
  - Ruby/Rails API backend: `http://localhost:3000`
  - Javascript/Angular frontend: `http://localhost:4200`
- [JavaDatabaseInterface](https://github.com/LucaPrevi0o/JavaDatabaseInterface) and [JavaServerInterface](https://github.com/LucaPrevi0o/JavaServerInterface)
  - Java repositories for a full-ORM-oriented transaction-based database framework and self-contained server infrastracture framework
  - Native support for JSON-file-based persistence strategies, with XML-oriented support integration planned
  - Annotation-based HTTP wiring and relational-based constraint violation check
- [NovaLanguage](https://github.com/LucaPrevi0o/NovaLanguage)
  - Full tokenization and AST (Abstract Syntax Tree) resolution from source file code
  - Grammar explaination and operator definition via recursive descent strategy
  - Intended implementation of full machine-code translation for execution-ready binary production
- [TensorPlusPlus](https://github.com/LucaPrevi0o/TensorPlusPlus) and [NeuralPlusPlus](https://github.com/LucaPrevi0o/NeuralPlusPlus)
  - C++ repositories for multi-dimensional tensor calculus and MLP-based neural network design framework, inspired by the NumPy/TensorFlow Python-based implementation
  - Pre-defined methods for model construction, training and validation from CSV datasets
